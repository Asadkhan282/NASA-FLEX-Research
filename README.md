# NASA FLEX Research



Research prototype for statistical analysis, exploratory data analysis, and machine learning using NASA PSI-69 Flame Extinguishment (FLEX) experimental data.



\## Project Overview



This project investigates flame-extinguishment outcomes using experimental measurements, statistical analysis, and machine-learning models.



It includes an interactive Streamlit dashboard.



\## Research Objectives



\- Explore experimental outcomes and fuel-related patterns.

\- Investigate oxygen concentration and flame-extinguishment outcomes.

\- Perform statistical analysis and multinomial logistic regression.

\- Evaluate machine-learning models using cross-validation.

\- Analyze prediction errors and feature importance.

\- Explore model predictions using the Prediction Lab.



\## Dataset

\## Limitations



\- This is a research prototype, not a validated physical simulator.

\- Predictions are based on the available experimental dataset.

\- The Completion class has limited observations and relatively weak predictive recall.

\- Statistical associations do not establish causation.

\- Model scores are not calibrated physical probabilities.

\- Independent experimental validation is still required.
